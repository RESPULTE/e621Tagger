# Hydra studio — current design direction (2026-11-05)

Keep e621's palette with polished typography, spacing and restrained motion. Preserve the real text-only gold hydra wordmark. Use only synthetic geometric demo art in previews; never send user media.

Verified palette: https://github.com/e621ng/e621ng/blob/master/app/javascript/src/styles/themes/_theme_hexagon.scss (2026-11-05). Page/media #020f23; foreground #102747 (slightly darker blue), navigation #152f56; panels/cards #1f3c67; text #ffffff; links #b4c7d9 and hover #e9f2fa; gold accent #e8c446; artist #f2ac08. Use readable pale semantic review colours #8ed8a1 and #f3a5a5. System font -apple-system/BlinkMacSystemFont/Segoe UI/sans-serif. Subtle corners: controls 6px, cards 8px, media 6–8px, floating dock 12px. Soft shadows and 160–280ms transitions with reduced-motion support. Full-width immersive viewer, only 18px desktop/8px mobile side padding, media up to 82dvh and natural aspect ratio. Do not shrink artwork to force all controls above the fold. No standalone save control. A small animated pink paw pad (#ff7eb6) appears at the media top-right only when favourited.

Gallery: image-first existing virtual grid; clear Positive/Negative counters with outlined check-circle and x-circle icons, tabular bold 20–22px numerals. Export is a prominent icon-and-word button in the project heading on every tab. Query, Tagged, Similarity, Downloads tabs remain compact.

Viewer: single wide column, highlighted artist heading with score and rating directly below. Navigation is quiet; omit manual zoom and compatible-MP4 buttons. Media uses its natural aspect ratio. Reserve the space below media for tags; no large paw or heart button. All tag categories are shown below the media in wrapping chips, never collapsed. Centered floating seamless review pill: Positive on the left, Negative on the right, one middle divider; save status remains accessible. Pressing an already selected review clears it; stay on the same artwork. Dock collapses when scrolling up and returns when scrolling down. Remove post-number headings, standalone source link, hide-tags controls, clear/undo buttons and Find More Like This button.

Similarity: filter first, selected source, bounded newest-first history and results. Use project name + artist + number when several source artworks share an artist. Unknown artist and Uploaded reference are honest fallbacks. No Search details or source-tag-count panel. Preserve operational errors and stage/progress.

Shared interaction: hold a thumbnail or enlarged media for two seconds. A fading circular search progress indicator fills during the hold. Only releasing within the starting content after two seconds submits. Moving, scrolling, blur, leaving, multi-touch or cancellation stops it. Shift+S is the keyboard equivalent. Do not add persistent instructional banners. Keep normal click-to-open, double-tap/double-click favourite toggle (repeat removes owned originals/partials), F keyboard equivalent, and native video controls. Thumbnails have only a big bold green tick and red cross.

Projects: no setup page. A small gold/navy fox stays at bottom left with the active canonical tag annotation to its bottom right with their lower edges aligned. Elastic opening reveals a navy panel with scrollable name/count rows, a 64px pull held for 1.5 seconds to open the e621 query composer, and left-swipe red trash actions without confirmation. Include keyboard-accessible New project and reveal-delete buttons. Keep positive/negative actions clear of the fox on narrow viewers. Restore the last selected project; when none is selected show a short fading notice. Respect reduced motion.

Animated viewer: native playback remains available. Optional single-line timeline follows the rendered media, with 16px insets matching Chromium's native seek track. A pale-gold vertical current-position notch stays on the track while the gold inverted map pin is pulled down. Successful samples leave gold vertical notches; decisions recolour them pale green/pink. Saved notches arrive with a small 380ms spring and tilt; reduced motion uses still markers. Focused samples reuse shared paw/hold-search gestures; sample borders reflect decisions.
