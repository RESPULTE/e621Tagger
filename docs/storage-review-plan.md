# Storage and review implementation contract

2026-10-24. Baseline: local ee5874d plus pre-existing dirty UI work; production ui-20261024-v4, schema v2 (verify schema and destination before release). No application writes while the independent audit is running.

- Lifecycle: fresh descending-ID upstream query pages live in bounded process memory with expiry. Browser/open/label paths never publish media. Reviews retain post identity, source metadata and query provenance; Tagged reads positive, negative and unsure labels. Clearing a review records an event and does not remove collection files. Legacy unreviewed archive is excluded from all new gallery/export membership; preserve it pending an approved cleanup plan.
- Media: transient bounded preview conversion in RAM, no disk thumbnail cache. Original/sample/video streaming retains range/HEAD handling and no-store responses. Review display refetches upstream metadata without replacing the immutable metadata in frozen datasets.
- Identity: one canonical project per target kind/id, resolved aliases before a serialized transaction. Query is discovery context, never a training label. Preserve duplicate projects/reviews in place, map their canonical root, surface conflicting labels and exclude unresolved conflicts from exports. Never sort arbitrary search syntax.
- Labels: one explicitly named binary target per project; positive/negative/unsure apply only to that target. Multi-tag search does not establish either independent label. Omit multi-tag training unless actual Hydra training/loader evidence proves a compatible contract.
- Queue: existing jobs table is the sole scheduler. Shared bounded download workers serve explicit collection and frozen dataset media exports, preserving interactive media capacity. States pending -> running -> done; transient failure -> pending with delayed retry; terminal failure -> failed; cancellation -> cancelled. Leases recover after restart; cooperative cancellation checks precede publication. Deduplicate intent and destinations; verify length/MD5 plus SHA256 records; atomic no-clobber publication; clean only owned partials. No deletion through double-tap.
- Compatibility: additive schema migration with SQLite online backup before mutation. Preserve frozen manifests, labels/events, existing collection files, manual files and unrelated dirty work. Canonical mapping is additive; no automatic conflict overwrite. Disable legacy durable discovery writes on all callers. Cache cleanup requires a separate inventory with exact owned paths and explicit approval if ownership is uncertain.
- UI: existing compact navy gallery, Query/Tagged/Downloads tabs; totals +/−/? only. Exports within Tagged. Delayed single pointer tap opens; second stationary tap queues an idempotent save, brief heart feedback and accessible button; movement/cancel abort gesture. Keyboard open remains immediate. Reduced motion uses nonanimated heart feedback.
- Verification: synthetic DB/disk deltas for fresh queries, review persistence and display; real worker overlap/capacity, integrity, retry/cancel/restart/partial publication; concurrent target/alias reuse and duplicate conflicts; export bytes/manifests; desktop/mobile Playwright, focused regressions/type/build/lint, final diff review. No real production labels or bulk media downloads. Prepare a reversible release; do not purge durable data.
